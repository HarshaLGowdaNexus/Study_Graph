# GLOSSARY (grows with the project)

Every time you use a technical term for the first time, add it here: term, plain meaning, a real-life analogy, and where it appears in this project.

| Term | Plain meaning | Analogy | Where in StudyGraph |
|---|---|---|---|
| Single Page Application (SPA) | A website that loads once and updates dynamically in the browser without reloading the page | A digital tablet menu where tapping tabs swaps pages instantly without ordering a whole new physical book | Frontend (React + Vite, D01) |
| Utility-First CSS | Styling elements directly using concise pre-made helper classes instead of writing custom CSS rules | Using color-coded Lego bricks with set shapes instead of molding plastic from scratch | UI Styling (Tailwind CSS, D02) |
| Force-Directed Graph | A visual network where nodes push apart like magnets and links pull together like springs to organize themselves naturally | A mobile hanging from the ceiling where stars and planets balance themselves through physics | 2D/3D Graph (react-force-graph, D03) |
| WebGL | A browser technology that draws high-speed 3D graphics directly using your computer's graphics card (GPU) | A 3D holographic projector built into your computer screen | 3D Graph rendering (D03) |
| Asynchronous Framework | A server architecture that handles multiple tasks concurrently without blocking or freezing while waiting for slow operations | A restaurant waiter who takes your order, gives it to the kitchen, and serves other tables while your food cooks, rather than standing motionless at the stove | Backend (FastAPI, D04) |
| Vector Embedding | An array of numbers (coordinates) that captures the conceptual meaning of a piece of text | A GPS latitude/longitude coordinate on a conceptual map where related ideas sit close together | Chunks, Topics & Search (text-embedding-004, D05, D10) |
| pgvector | A database extension for PostgreSQL that enables storing and searching high-dimensional vectors directly with SQL | A high-tech filing cabinet with a built-in compass that points you to folders closest in meaning | Database (Supabase Postgres, D05) |
| Cosine Similarity | A mathematical formula measuring the angle between two vectors to see how closely their meanings match (from 0 to 1) | Checking how closely two compass needles point in the same direction, regardless of how long the needles are | Topic deduplication & link finding (D05, D10) |
| Object Storage | Cloud storage designed specifically for storing unstructured files (PDFs, images, slides) rather than rows in a table | A secure warehouse locker where physical packages are stored and given barcode tracking IDs | File storage (Supabase Storage, D06) |
| Background Task | A slow computation executed by the server quietly behind the scenes so the web page doesn't time out or freeze | Placing an order at a deli counter and receiving a vibrating buzzer while the chef prepares your meal | Document Ingestion Pipeline (D07) |
| Multimodal Vision LLM | An artificial intelligence model that can process both visual images and text simultaneously | A bilingual scholar who can look at a photograph of an ancient, messy scroll and transcribe it into clean, typed English | OCR for handwritten notes (Gemini Flash, D08) |
| Structured Outputs / JSON Schema | Forcing an AI model to return its response in strict, machine-readable JSON matching an exact blueprint | Giving a contractor a pre-printed form with required checkboxes and fields instead of letting them write freeform prose on a napkin | Topic extraction & Link Judge (Gemini Flash, D09) |
| Louvain Community Detection | A graph mathematics algorithm that finds natural clusters of densely connected nodes in a network | An aerial view of a party identifying natural social circles based on who is actively talking to whom | Topic Clustering (NetworkX, D11) |
| JWT (JSON Web Token) | A digitally signed, tamper-proof digital pass that proves a user's logged-in identity to the server | A wristband given at a concert entrance that lets you enter VIP areas without re-showing your passport every time | User Authentication (Supabase Auth, D13) |
| Document Parser | A software library that unpacks file formats like PDF or PPTX to extract raw text, metadata, and page numbers | An intake clerk who opens shipping envelopes, sorts the contents, and stamps page numbers on every sheet | Text extraction & Scan detection (pdfplumber, python-pptx, D15) |
